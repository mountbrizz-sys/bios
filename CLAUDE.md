# Bios — CLAUDE.md

Personal productivity PWA: habits, calendar, deadlines, tasks, weekly review,
cloud sync. Single-file vanilla JS/HTML/CSS. Sole developer/user: Brizz.
Live at bios-lake.vercel.app.

## Files
- `index.html` — the entire app (HTML/CSS/JS in one file)
- `sw.js` — service worker; bump `CACHE = 'bios-vNN'` on every deploy
- `manifest.json`, `config.js` (Supabase credentials — public, protected by RLS)
- `tests/` — jsdom regression suite, one file per fixed bug/feature

## Deploy rule (standing)
Run the full test suite before every deploy. Fix failures before shipping,
never ship with a known-red test.

```
npm install       # once
npm test          # before every deploy
```

## Standing principles
- User-set values always take priority over auto-calculated ones.
- A failed network fetch must never be treated as "no data exists" —
  silent overwrites from a failed fetch are a critical failure mode.
- iOS localStorage eviction is real and has caused live data loss —
  this is why cloud sync exists at all.

## Testing discipline
- jsdom tests live in `tests/`, one file per bug/feature, named
  `test_<what-it-covers>.js`. Keep adding to this suite — it's the real
  regression safety net across sessions.
- Pin "today" to a fixed fake `Date` in every calendar-related test —
  never let tests depend on the real current date.
- Re-view a file immediately before editing it; stale DOM/content
  references after a re-render are a common source of false failures.
- Isolate test-harness bugs from real app bugs before trusting a
  failure — a wrong assumption in the test itself (wrong seed data,
  a substring collision, a timing assumption) has caused false
  failures multiple times in this project's history. Confirm which
  one it is before "fixing" anything.
- A passing test suite from an old sandbox path won't work verbatim —
  paths must be relative to `tests/` (e.g. `../index.html`), not
  absolute paths from wherever they were first written.

## Deploy process
1. Edit `index.html` / `sw.js`.
2. Bump the `CACHE` version string in `sw.js`.
3. `npm test` — all suites must pass.
4. Commit and push — Vercel's GitHub integration (Hobby/free tier)
   auto-deploys every push to main.

## Known open items (carried over from prior sessions)

  issue as the "editing one recurring appointment reverted on reload" bug

  properly. Not yet implemented.
- Historical budget/drift data cannot be reconstructed before the date
  `bios_day_snapshot` tracking shipped — drift detection only works
  forward from that point.
